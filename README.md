# Employee Management System

A simple Employee Management System built using HTML, CSS, and JavaScript.

## Features

- Display active employees
- Search employees by ID and name
- Filter employees by department
- Calculate total and average salary
- Apply 10% salary increments
- View department statistics
- Find highest-paid and lowest-paid employees
- Sort employees by salary
- Add and remove employees
- Display active and inactive employee information

## Technologies Used

- HTML
- JavaScript

## JavaScript Concepts

- Array Methods: `map()`, `filter()`, `find()`, `reduce()`
- Functions
- Array Destructuring and Spread Operator
- DOM Manipulation

## Project Purpose

To practice JavaScript array methods, functions, and employee data management.
